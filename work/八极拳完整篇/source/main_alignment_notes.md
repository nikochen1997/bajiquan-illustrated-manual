## 浏览器截图注意

- 已实际使用 getScreenshot({emit:false})，返回 JPEG Uint8Array；已实测首字节 FF D8 FF。
- 已实际使用 tab.screenshot({clip:{x,y,width,height}}) 获取视频区域。当前查看视口的 video 矩形为 x=290、y=68、width=341、height=606；其他视口需重新读取 DOM getBoundingClientRect。
- 标准 Node 文件保存可用 import('node:fs/promises') 的 writeFile；本代理仅写本记录和 JSON，未保存参考截图。
- 快速 seek 后首张截图可能还是旧帧；currentTime 与 readyState=4 本身不足以证明画面已经刷新。
- 已从真实 DOM 核实缓冲指示器 class 为 ytp-spinner，可用 locator('.ytp-spinner').waitFor({state:'hidden',timeoutMs:10000})。必要时丢弃第一次截图，再读后续稳定画面。
- evaluate 的只读 DOM 代理未提供 video.seeking、requestVideoFrameCallback、addEventListener、requestAnimationFrame，不能编造 seeked 等候代码。
- 此字幕版逐帧步长约 1/30 秒，三套连打候选约 1/24 秒，不能混用步数。
